# StuBud — AI Student Mentor

StuBud is an AI-powered student counselling chatbot designed to guide students through academic challenges, stress, and career decisions.

## Key Features
- Context-aware conversations
- Personalized student profiling
- Memory using MongoDB
- Modern glass UI interface
- Emotional + academic support

## Tech Stack
- Python (Flask)
- Google Gemini API
- MongoDB Atlas
- HTML, CSS, JavaScript

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Create a `.env` file:
   API_KEY=your_api_key

3. Run:
   python app.py
